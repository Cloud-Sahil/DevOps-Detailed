# 🔹 About This Repository

This repository documents my journey into DevOps, where I am learning to automate, build, test, and deploy applications efficiently. It acts as a central hub for my notes, practical implementations, and real-world DevOps workflows.

I am working with tools like Git, Docker, Kubernetes, and CI/CD platforms such as Jenkins, GitHub Actions, and GitLab.

I am also exploring Infrastructure as Code using Terraform, improving code quality with SonarQube, and monitoring applications using Datadog.
